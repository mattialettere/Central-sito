In short: in Central, messages, photos, videos, voice notes, whiteboards, trip locations and SOS alerts are end-to-end encrypted on the phone with X25519 and AES-256-GCM. Private keys stay on the devices and the cryptographic code is public on GitHub. The server does see metadata, meaning who talks to whom and when, and the system does not yet offer forward secrecy.

What end-to-end encryption means

With end-to-end encryption a message is encrypted on the sender's phone and decrypted only on the recipient's phone. The server in between carries unreadable data: whoever runs the service, a hosting provider or someone who broke into the server cannot read the content.

This is different from encryption "in transit" (HTTPS), which protects data while it travels but leaves it readable to the server. The EFF guide "What should I know about encryption?" explains the difference well.

How it works in Central

Keys

On first sign-in the phone generates an X25519 key pair for your account. The public key goes to the server so others can encrypt for you; the private key stays on the phone, stored with the system's protections (Keychain on iPhone, Keystore on Android). It only leaves the phone if you choose to save a backup, and then it is already encrypted.

One-to-one chats

The two phones derive a shared key with X25519 and encrypt every message with AES-256-GCM, which also protects against tampering: an altered message is rejected.

Groups

Each group has its own AES-256 key, delivered to every member encrypted with their public key.

Photos, videos and files

Every file is encrypted with AES-GCM before upload. It reaches the storage server, in France, already encrypted.

Key backup

To recover your chats on a new phone you can save a key backup protected by a passphrase. The backup key is derived from the passphrase with PBKDF2-SHA256 at 210,000 iterations, which makes guessing it slow and expensive.

Voice calls

Call audio travels encrypted between the two phones with DTLS-SRTP, the WebRTC standard. When a relay server (TURN) is needed, it carries the encrypted audio without being able to listen to it.

What encryption does not cover

We prefer to say this plainly, because promising "absolute security" is not honest for any app.

  • Metadata: the server knows who is in touch with whom, when messages are sent and how large they are. It needs this to deliver them.
  • No forward secrecy: Central does not change keys with every message the way "double ratchet" protocols do (for example Signal's). If someone obtained a device's private key, they could also read past encrypted messages they had stored.
  • The phone itself: anyone with your unlocked phone sees your chats as you do. Lock your screen with a passcode.
  • Safe zones: to alert your followers when you leave a zone, the server knows the zone's centre and radius and the exit locations, which it deletes after 3 days.
  • Not anonymous: you need an account to use Central. Encryption protects content; it does not hide who you are.

Open and verifiable code

Central's cryptographic code is published under the Apache-2.0 licence in the central-crypto repository, with test vectors shared between Android and iPhone. Anyone can check that both apps encrypt the same way. The rest of the app is not open source.

Where the data lives

Central's server runs on Railway in its European region; Railway is a US company. Encrypted photos, videos and files are stored by Scaleway in France. Some technical services come from US providers: push notifications (Google Firebase and Apple), maps (Mapbox) and email (Resend). The full list is in the privacy policy.

How to choose a private messaging app

A few useful questions that apply to any app:

  • Is end-to-end encryption on for every chat, or do you have to turn it on?
  • Is the cryptographic code public and verifiable?
  • Does the app live on advertising or sell data?
  • Does the company say openly what it can see, such as metadata?
  • Where are the servers and which providers handle the data?

If what you need most is maximum message protection, a dedicated app such as Signal remains the benchmark. Central is designed for people who want encrypted chat and personal safety tools in the same app.
